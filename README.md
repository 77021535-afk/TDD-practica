## Descripción
El Desarrollo Guiado por Pruebas (Test-Driven Development) es una disciplina de diseño e ingeniería de software que sigue un ciclo iterativo y corto compuesto por tres fases principales Red(Escribir primero una prueba automatizada que falle), Green(Escribir el código mínimo necesario), Refactor (Mejorar la estructura, legibilidad y eficiencia del código manteniendo las pruebas en verde)
